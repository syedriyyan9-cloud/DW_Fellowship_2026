Creating REST API - Supporst JSON

routes:

GET /users - List all users - HTML - DONE
GET /api/users - List all users - DONE

GET /api/uses/1 - get the user with ID 1 - DONE
Dynamic path parameters
Get /api/users/:id
:id -> variable - dynamic

POST /api/users = Create new user

PATCH /api/user/id - Edit the user with ID 1

DELETE /api/users/1 - delete the user with ID 1

## prepend path with /api to suggest that data is given as a JSON
## if not prepended with /api then this suggests that html page is rendered
